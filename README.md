# Курс молодого бойца по CTF — подготовка к муниципальному этапу ВсОШ по ИБ

Учебный **курс** для школьников-новичков по подготовке к муниципальному этапу всероссийской
олимпиады по информационной безопасности (формат CTF, Jeopardy).

Курс разбит по темам — **по одному `.md` на главу**. Начинать с **`00-about.md`** (там же общее
оглавление).

---

## 1. Идея курса в одном абзаце

На туре участник сидит **офлайн**: нет интернета, онлайн-тулз (CyberChef, dcode), калькулятора,
**нельзя принести никаких материалов**. Есть только голова, терминал Linux и Python в выданной
виртуалке. Поэтому курс — не шпаргалка, а **тренажёр для наработки навыка заранее**, чтобы приёмы
сидели в голове и в пальцах. Философия: *опознал категорию → применил технику → получил флаг*.

## 2. Аудитория

Абсолютные новички: терминал видели пару раз, Python только начинают. Отсюда — никакой воды и
академизма, формат «увидел X → сделал Y», упор на Python + немного C/C++ (для чтения в реверсе).

## 3. Потолок сложности

Целимся в **муниципальный этап** (максимум — региональный). Материал «на вырост» помечен значком 🔺.

## 5. Договорённости по стилю (соблюдать при доработке)

1. **«Курс молодого бойца», а не справочник.** Тон «разбери и набей руку». Не «шпаргалка на тур».
2. **Только синтетические примеры** (не реальные олимпиадные задачи). Флаги вида `flag{...}`.
3. **Каждый пример кода проверять запуском** перед добавлением.
4. **Не упоминать статьи УК.** Этика — мягко.
5. **Потолок — муниципал** (сложнее → 🔺).
6. **Python + немного C/C++**, всё автономно; где обычно утилита — показывать и ручной способ на Python.
7. **Формат:** таблицы, однострочники bash, Python-шаблоны с комментариями, блок «вижу X→делаю Y» и итог в конце главы.

Полные правила для ИИ-агентов — в `AGENTS.md` (и `CLAUDE.md`, который на него ссылается). Их
автоматически подхватывают Codex и Claude Code при работе в этой папке.

## 6. Как дорабатывать

- Правим **нужный файл главы** (один файл = одна тема).
- Перед добавлением примера — **прогнать его** (`python3`, при необходимости `gcc`).
- Сохранять нумерацию внутри главы и **сквозную нумерацию тренировок**; при сдвиге — перенумеровать.
- Обновлять оглавление в `00-about.md` при добавлении/переименовании глав.
- Собрать единый файл (например, для PDF): `cat 0*-*.md 1*-*.md > _full.md`.

### Бэклог идей

- Готовые синтетические «задачи-пакеты» (файл + условие + разбор + флаг) для самостоятельного решения.
- Раздел «частые ошибки новичков» по каждой категории.
- PDF-версия для печати (через `pandoc`/`weasyprint`).
