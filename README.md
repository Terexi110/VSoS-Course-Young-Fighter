# Курс молодого бойца по CTF - подготовка к муниципальному этапу ВсОШ по ИБ

Учебный **курс** для школьников-новичков по подготовке к муниципальному этапу всероссийской
олимпиады по информационной безопасности (формат CTF, Jeopardy).

Курс разбит по темам - **одна папка на тему**, внутри три уровня сложности. Начинать с
**`00-about.md`** (там же общее оглавление).

---

## 1. Идея курса в одном абзаце

На туре участник сидит **офлайн**: нет интернета, онлайн-тулз (CyberChef, dcode), калькулятора,
**нельзя принести никаких материалов**. Есть только голова, терминал Linux и Python в выданной
виртуалке. Поэтому курс - не шпаргалка, а **тренажёр для наработки навыка заранее**. Философия:
*опознал категорию -> применил технику -> получил флаг*.

## 2. Три уровня сложности

Каждая тема дана на трёх уровнях:

- **`easy.md`** - самая база, коротко: чтобы абсолютный новичок начал.
- **`medium.md`** - основной рабочий уровень (то, что нужно на муниципале).
- **`hard.md`** - продвинутое, "на вырост" к региональному уровню (помечено 🔺).

Проходить можно двумя способами: либо всю тему снизу вверх (easy->medium->hard), либо весь курс
одним уровнем (сначала все `easy`, потом все `medium`...).

## 3. Аудитория и потолок

Абсолютные новички (терминал видели пару раз, Python только начинают). Формат "увидел X -> сделал Y",
Python + немного C/C++. Потолок - муниципальный этап (hard - максимум региональный).

Тренировки (🎯) идут внутри каждого файла; в medium - сквозная нумерация 1-26.

## 5. Договорённости по стилю (соблюдать при доработке)

1. "Курс молодого бойца", а не справочник; не "шпаргалка на тур".
2. Только **синтетические** примеры (не реальные олимпиадные задачи). Флаги вида `flag{...}`.
3. **Каждый пример кода проверять запуском** перед добавлением.
4. **Не упоминать статьи УК.** Этика - мягко.
5. Потолок - муниципал (hard -> 🔺).
6. Python + немного C/C++, всё автономно.
7. Таблицы, однострочники bash, Python-шаблоны с комментариями; в medium - блок "вижу X->делаю Y" и итог.

Полные правила для ИИ-агентов - в `AGENTS.md` (и `CLAUDE.md`, который на него ссылается): их
автоматически подхватывают Codex и Claude Code при работе в этой папке.

## 6. Как дорабатывать

- Правим нужный уровень темы: `NN-тема/{easy|medium|hard}.md`.
- Перед добавлением примера - прогнать его (`python3`/`gcc`).
- Обновлять оглавление в `00-about.md` при добавлении/переименовании тем; сохранять футер-ссылки.
- Единый файл для PDF: `cat 00-about.md */easy.md */medium.md */hard.md 11-appendix.md > _full.md`.

### Бэклог идей

- Готовые синтетические "задачи-пакеты" (файл + условие + разбор + флаг) для самостоятельного решения.
- PDF-версия для печати (через `pandoc`/`weasyprint`).

## 7. Статус

Готов полный черновик: 10 тем x 3 уровня (easy/medium/hard) + вводная + приложения. Все примеры кода
проверены на запуск.
