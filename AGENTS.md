# AGENTS.md - правила для ИИ-агента, работающего над этим проектом

> Этот файл автоматически читают ИИ-агенты (Codex, Claude Code и др.) в начале сессии.
> `CLAUDE.md` рядом ссылается сюда - правила едины для всех инструментов.

## Что за проект

Учебный **курс** для школьников-новичков по подготовке к **муниципальному этапу ВсОШ по
информационной безопасности** (CTF, формат Jeopardy). Это не код, а учебный материал.

Курс разбит по темам - **одна папка на тему**, внутри три уровня сложности:
`easy.md` -> `medium.md` -> `hard.md`. Точка входа и оглавление - `00-about.md`.

## Три уровня - что куда писать

- **easy.md** - самая база темы, коротко. Минимум понятий, 2-4 команды/крошечный пример, 1
  тренировка. Цель - чтобы абсолютный новичок начал. Много текста НЕ надо.
- **medium.md** - основной рабочий уровень (то, что реально нужно на муниципале).
- **hard.md** - продвинутое, "на вырост" к региональному уровню (помечай 🔺). Более сложные техники
  и атаки, но без ухода за региональный потолок.

Один и тот же навык на трёх уровнях должен **наращиваться**, а не повторяться.

## Идея (держи в голове при любой правке)

Участник на туре **офлайн**: нет интернета, онлайн-тулз, калькулятора; **ничего нельзя принести**.
Только терминал Linux и Python в выданной виртуалке. Поэтому это **"курс молодого бойца"** -
тренажёр для наработки навыка заранее, а не шпаргалка на тур. Логика тем: *опознал категорию ->
применил технику -> получил флаг*. Аудитория - новички. Пиши прикладно, без воды и академизма.

## Жёсткие правила (НЕ нарушать)

1. **Тон "курса", с тренировками (🎯).** Не подавать как "шпаргалку на тур".
2. **Только синтетические примеры.** НЕ использовать реальные олимпиадные задачи и не приводить их
   как примеры. Все шифротексты/флаги/числа - выдуманные.
3. **Каждый пример кода проверять запуском** перед добавлением; результат в комментарии должен
   совпадать с реальным. Флаги - вида `flag{...}`, осмысленные, реально получаемые из кода.
4. **Не упоминать статьи УК** и правовую ответственность. Этика - мягко: "работаешь только со
   своими задачами и своим рабочим местом".
5. **Потолок - муниципал** (medium); hard - максимум региональный, под значком 🔺.
6. **Язык примеров - Python + немного C/C++.** Всё автономно; где обычно утилита - показывать и
   ручной способ на Python.
7. **Формат:** таблицы; однострочники bash; Python-шаблоны с комментарием почти к каждой строке;
   в конце medium-главы блок "вижу X -> делаю Y" и короткий итог; футер со ссылками на соседние
   уровни и оглавление.

## Легенда значков (использовать те же)

- `$ команда` - терминал; `>>> код` - интерактивный Python.
- 🎯 тренировка * 🔺 "на вырост" (регион) * ⚠️ ошибка/предупреждение * 💡 трюк.

## Структура файлов

```
00-about.md                 <- о курсе + оглавление (точка входа, без уровней)
01-intro-ctf/               <- тема = папка
   easy.md  medium.md  hard.md
02-linux/        {easy,medium,hard}.md
03-python/       {easy,medium,hard}.md
04-crypto/       {easy,medium,hard}.md     <- самая большая тема
05-forensics-stego/ {easy,medium,hard}.md
06-web/          {easy,medium,hard}.md
07-networking/   {easy,medium,hard}.md
08-reverse/      {easy,medium,hard}.md
09-pwn/          {easy,medium,hard}.md
10-misc/         {easy,medium,hard}.md
11-appendix.md              <- приложения A-D (без уровней)
AGENTS.md  CLAUDE.md  README.md
```

Ключевой сквозной навык - **читать алгоритм шифрования/проверки и писать к нему дешифратор**
(обращать операции в обратном порядке; где трудно - перебор каждого байта 0..255). Связывает
`04-crypto` и `08-reverse`.

## Как проверять примеры кода (обязательно)

```bash
python3 -I -c '...'       # прогнать крипто/misc-пример и сверить вывод с комментарием
gcc -o /tmp/x x.c && ...  # для C/C++ примеров
```
Проверочные скрипты держать ОТДЕЛЬНО; в курс попадает только проверенный код.

## Как вносить правки

- Правь нужный файл нужного уровня: `NN-тема/{easy|medium|hard}.md`.
- Нумерация тренировок **внутри своего файла** (easy - обычно 1; medium - сквозная 1..23; hard -
  "Тренировка (hard)"). Нумерацию разделов внутри главы (`## 4.1`, ...) сохраняй.
- Добавляешь/переименовываешь тему - **обнови оглавление в `00-about.md`** и дерево в этом файле.
- Сохраняй футер со ссылками (`[easy] * [medium] * [hard] * [оглавление]`).
- Собрать всё в один файл (для PDF):
  `cat 00-about.md */easy.md */medium.md */hard.md 11-appendix.md > _full.md`
  (или один уровень: `cat */easy.md > _easy.md`).
