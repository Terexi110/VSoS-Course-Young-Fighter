# CLAUDE.md

Правила работы над этим проектом едины для всех ИИ-инструментов и описаны в **`AGENTS.md`**
(в той же папке). Прочитай его перед любой правкой.

@AGENTS.md

Кратко самое важное:
- Это **курс** по CTF для школьников-новичков (муниципальный этап ВсОШ по ИБ). Курс разбит
  **по папкам-темам**, в каждой три уровня: `easy.md` -> `medium.md` -> `hard.md`. Точка входа и
  оглавление - `00-about.md`. Общие файлы без уровней: `00-about.md`, `11-appendix.md`.
- Уровни: **easy** - самая база, коротко; **medium** - рабочий уровень (муниципал);
  **hard** - продвинутое, "на вырост" к региону (🔺). Навык должен наращиваться от уровня к уровню.
- Тон - "курс молодого бойца" с тренировками, не шпаргалка.
- Только **синтетические** примеры (не реальные олимпиадные задачи). Флаги вида `flag{...}`.
- **Каждый пример кода проверять запуском** (`python3`/`gcc`) перед добавлением.
- **Не упоминать статьи УК.** Python + немного C/C++.
- Правишь уровень темы `NN-тема/{easy|medium|hard}.md`; при добавлении темы обновляешь оглавление в
  `00-about.md`; сохраняешь футер со ссылками на соседние уровни.
