# Глава 2 (easy). Терминал Linux — самая база

Терминал — это окно, где команды пишут текстом. Нужно знать всего несколько команд.

## Главное различие с Windows

В терминале не работают Ctrl + C, Ctrl + V, Ctrl + Z. Всегда надо добавлять + Shift.
Nano и vim - основные текстовые редактора в линуксе
Как выйти из nano: Ctrl + X -> Y (N - не сохранять)
Как выйвти из vim: Esc, затем :wq (w - записать, q - записать). Выйти без сохранения :q!
Чтобы начать писать в vim надо нажать Esc (режим команд) и затем i/insert (режим редактирования)

## Где я и что рядом

```bash
pwd            # показать текущую папку
ls             # список файлов
ls -la         # список со всеми файлами (в т.ч. скрытыми) и подробностями
cd папка       # зайти в папку
cd ..          # выйти на уровень выше
```

## Посмотреть файл

```bash
cat файл.txt         # показать содержимое текстового файла
file файл            # что это за файл (картинка? программа? текст?)
```

## Две самые полезные команды на CTF

```bash
strings файл          # вытащить читаемый текст из любого файла
grep слово файл       # найти строки со словом
```

Их обычно соединяют «трубой» `|` — вывод первой идёт во вторую:

```bash
strings файл | grep flag      # искать флаг в любом файле
```

## Если забыл команду

```bash
grep --help     # краткая подсказка по команде
# или
man grep    # полная документация 
```

🎯 **Тренировка.** Зайди в любую папку (`cd`, `ls`), выбери файл и прогони по нему `file`, затем
`strings файл | grep -i flag`. Привыкни к этим трём командам.
